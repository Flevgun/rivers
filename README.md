# Rivers

Личный клиент для VLESS. Подписки, маршруты, геофайлы, ядра Xray и sing-box, логи. Имя от семьи Rivers.

Десктопная сборка для Windows. Установщик не нужен: распаковал архив и запустил `Rivers.exe`, откроется своё окно, не браузер.

## Скачать

Один релиз, два файла: [Rivers 1.5.30](https://github.com/Flevgun/rivers/releases/tag/v1.5.30).

**[Windows 64-bit](https://github.com/Flevgun/rivers/releases/download/v1.5.30/Rivers-windows-64.zip)**

1. Распакуй архив в любую папку.
2. Запусти `Rivers.exe`.
3. Выбери сервер и нажми круглую кнопку питания. Ядро Xray или sing-box стартует само.
4. Меню слева спрятано: кнопка слева сверху открывает его и закрывается, когда выбран раздел.
5. Если вышла новая версия, сверху появится плашка. Кнопка открывает страницу релиза. В настройках есть «Проверить».
6. Режим **Системный прокси** работает без прав администратора. **TUN** есть только у sing-box, забирает весь трафик и требует запуск от имени администратора.
7. Тема меняется в «Настройках»: Мята, Ночь, Бумага, Янтарь.
8. Крестик и сворачивание прячут окно в трей. Полный выход — пункт «Выход» в трее.

Windows может написать, что издатель неизвестный. Это из-за того, что сборка без подписи. Нажми «Подробнее», затем «Выполнить в любом случае».

**[Android](https://github.com/Flevgun/rivers/releases/download/v1.5.30/Rivers-android.apk)**

Нужен Android 10 или новее. Скачай apk из того же релиза, разреши установку из этого источника и открой файл. Внизу три иконки: главная, серверы, настройки. Если вышла новая версия, на главной появится плашка: нажатие скачает apk и откроет установку. Та же проверка есть в настройках. Подписки сворачиваются. Приложения, логи и тема лежат в настройках.

## Что внутри

- Подписки и отдельные ссылки `vless://`
- Режимы TUN и системный прокси
- Пресеты маршрутов: всё в прокси, RU напрямую, игры и RU, свой набор
- Ядра Xray и sing-box, конфиг можно править руками
- Геоисточники, логи, статистика
- Сворачивание в трей

## Сборка из исходников

Нужен Node.js 22.

```bash
npm install
NITRO_PRESET=node npm run build
cd desktop && npm install && npm run pack
```

Архив появится в `desktop/dist/Rivers-windows-64.zip`.
