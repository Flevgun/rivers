# Rivers

Личный клиент для VLESS. Подписки, маршруты, геофайлы, ядра Xray и sing-box, логи. Имя от семьи Rivers.

Десктопная сборка для Windows. Установщик не нужен: распаковал архив и запустил `Rivers.exe`, откроется своё окно, не браузер.

## Скачать

**[Rivers для Windows 64-bit](https://github.com/Flevgun/rivers/releases/download/v1.3.1/Rivers-windows-64.zip)**

1. Распакуй архив в любую папку.
2. Запусти `Rivers.exe`.
3. Выбери сервер и нажми кнопку питания. Ядро Xray или sing-box стартует само.
4. Режим **Системный прокси** работает без прав администратора: в браузере сайты `.ru`, `.su`, `.рф` и рунет идут напрямую, остальное через VPN. **TUN** есть только у sing-box, забирает весь трафик и требует запуск от имени администратора.
5. Крестик и сворачивание прячут окно в трей. Полный выход — пункт «Выход» в трее. Кнопка питания выключает профиль и снимает системный прокси. В логах видно, куда ушёл адрес: напрямую, в прокси или в блок.

Windows может написать, что издатель неизвестный. Это из-за того, что сборка без подписи. Нажми «Подробнее», затем «Выполнить в любом случае».

**[Rivers для Android](https://github.com/Flevgun/rivers/releases/download/v1.4.2/Rivers-android.apk)**

Нужен Android 10 или новее. Скачай apk, разреши установку из этого источника и открой файл. При первом включении система спросит разрешение VPN. Вставь ссылку `vless://` или подписку, выбери сервер и нажми «Включить». Рунет идёт напрямую, остальное через VPN. Внизу три вкладки: главная, приложения и логи. Во вкладке «Приложения» отмеченные программы идут либо напрямую, либо только они через VPN — это поверх правил конфига. Это отдельное приложение, не окно Windows.

## Что внутри

- Подписки и отдельные ссылки `vless://`
- Режимы TUN и системный прокси
- Пресеты маршрутов: всё в прокси, RU напрямую, игры и RU, свой набор
- Ядра Xray и sing-box, конфиг можно править руками
- Геоисточники, логи, статистика
- Сворачивание в трей

## Сборка из исходников

Нужен Node.js 22.

```bash
npm install
NITRO_PRESET=node npm run build
cd desktop && npm install && npm run pack
```

Архив появится в `desktop/dist/Rivers-windows-64.zip`.
